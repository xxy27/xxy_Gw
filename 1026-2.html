三大程序结构

顺序结构

代码自上而下逐句执行，是最基本的结构。

var xxy_a = 1;
var xxy_b = 2;
console.log(xxy_a + xxy_b); // 3

分支结构（条件）

根据条件是否成立，选择执行不同的代码。常用 if/else、switch。

if (xxy_score >= 60) {
  console.log("及格");
} else {
  console.log("不及格");
}

循环结构

重复执行某段代码，直到条件不满足。常用 for、while、do...while。

for (var xxy_i = 1; xxy_i <= 5; xxy_i++) {
  console.log(xxy_i);
}
