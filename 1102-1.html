JSON 数据格式

JavaScript Object Notation · 轻量级数据交换格式

JSON 是什么

JSON（JavaScript Object Notation）是一种轻量级的数据交换格式，采用完全独立于语言的文本格式来存储和表示数据，易于人阅读和编写，也易于机器解析和生成，是目前前后端数据传输最常用的格式。
  • 数据由键值对组成，键必须用双引号包裹
  • 数据由逗号分隔，大括号保存对象，方括号保存数组
  • 文件扩展名为 .json，MIME 类型为 application/json

JSON 的六种值类型

字符串 String

必须使用双引号，不支持单引号。

"name": "徐昕妤"

数值 Number

整数或浮点数，不支持十六进制与 NaN。

"age": 19

布尔 Boolean

只有 true 和 false 两个值，小写。

"isStudent": true

空值 Null

表示空值，注意不能写成 NULL 或 Null。

"phone": null

数组 Array

方括号包裹的有序值列表。

"hobby": ["html", "css", "js"]

对象 Object

大括号包裹的无序键值对集合，可嵌套。

"score": { "js": 95, "css": 88 }

JSON 与 JavaScript 对象的区别

对比项JSONJS 对象字面量
键（属性名）必须用双引号 "name"可省略引号 name
字符串值只能双引号单、双引号均可
函数 / undefined不允许出现可以有
末尾逗号不允许允许（现代浏览器）
本质字符串（文本格式）内存中的对象（可以操作）

小结：JSON 只是一种字符串格式；JSON.parse() 让字符串变回可以操作的对象，JSON.stringify() 让对象变回可以传输的字符串， 二者互为逆操作，是前后端交换数据的基础。注意 JSON 的键必须双引号、不能含函数和 undefined。
