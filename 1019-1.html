Font Awesome
字体图标

Font Awesome 采用 字体图标（Icon Font） 方案：先把一组矢量字形打包成 woff2 / ttf 字体文件，再通过 @font-face 注册字体， 用 <i class="fa-solid fa-xxx"> 指定某个字形，最后用 CSS 的 font-size 与 color 像控制文字一样控制图标。本页所有资源均已下载到本地 cdn/fontawesome/，无需联网即可使用。

06

实现方式

字体图标的三个要素：
1）引入本地 CSS，其中通过 @font-face 注册字体文件；
2）字体文件（woff2 / ttf）按 cdn/fontawesome/webfonts/ 存放，与 CSS 保持相对路径；
3）HTML 中用 <i> 的类名选择字形，用 CSS 控制字号与颜色。 <link rel="stylesheet" href="cdn/fontawesome/css/all.min.css"> <i class="fa-solid fa-rocket"></i> <i class="fa-brands fa-github" style="font-size:2rem;color:#bd4939"></i>
