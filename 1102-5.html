JavaScript 两种定时器

setTimeout（延时执行一次）· setInterval（每隔一段时间重复执行）

返回首页

概念与区别

JavaScript 是单线程语言，定时器并不是"真的多线程"，而是由浏览器计时，时间到了把回调函数放进任务队列，等主线程空闲时再执行。
  • setTimeout(fn, ms)：延时指定毫秒后只执行一次，返回一个定时器 ID
  • setInterval(fn, ms)：每隔指定毫秒重复执行，返回一个定时器 ID
  • clearTimeout(id) / clearInterval(id)：按 ID 取消对应定时器
  • 毫秒单位，1000 ms = 1 秒；定时器时间不精确，只保证"不早于"指定时间

setTimeout · 延时执行一次

常用于延迟提示、动画等待、防抖等"只做一次"的场景。

var xxy_id = setTimeout(function () {
    alert("3 秒到了");
}, 3000);

// 取消：clearTimeout(xxy_id)

setInterval · 周期重复执行

常用于时钟、轮播、倒计时、实时刷新等"持续重复"的场景。

var xxy_id = setInterval(function () {
    console.log("每 1 秒执行一次");
}, 1000);

// 停止：clearInterval(xxy_id)

实验一 · setTimeout 延时提示

设定延时时长，到点触发一次

点击"开始计时"后开始倒计时，到达设定时间时舞台变红并弹出提示；在倒计时结束前点"取消定时器"可调用 clearTimeout 中止本次任务。

实验二 · setInterval 秒表与进度条

每 100 毫秒执行一次的回调

开始后 setInterval 每 0.1 秒把计数 +1 并刷新显示，同时驱动进度条；点"暂停"用 clearInterval 停止，"重置"清零。

实验三 · setInterval 实时时钟

每秒刷新一次当前时间

进入页面后时钟自动运行（setInterval 每 1000 ms 更新一次），可暂停/恢复，直观展示"重复执行"的效果。

--:--:--
对比记忆：setTimeout = 一次性的闹钟（响一次就结束），setInterval = 循环的节拍器（按固定间隔一直响，直到 clearInterval）。 两者都用同一个数字 ID 机制，取消时务必传入对应的定时器 ID，否则清除不掉。
