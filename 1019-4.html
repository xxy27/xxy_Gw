移动端底部导航
SVG 图标方案

基于 font/iconfont.js 导出的 SVG symbol 精灵图，实现一个固定定位、4 项等分、宽度自适应的移动端底部导航。 页面中以 <svg><use xlink:href="#icon-xxx"></use></svg> 引用矢量图标， 生成的 <svg> 是真实 DOM 节点，可用 CSS 的 fill 与尺寸控制；并在右上角叠加数字徽章与红点。

  • SVG 矢量图标
  • 固定定位 bottom
  • 4 项 flex 等分
  • 宽度自适应
  • 数字徽章
  • 红点提示

数字徽章与红点

徽章与红点都绝对定位于图标右上角，通过外层包裹元素定位，不占用布局空间。

9+

数字徽章

用于展示未读数量，超过上限时用 9+ 形式；圆角胶囊 + 白色描边，避免与图标粘连。

红点提示

仅提示“有新内容”，不显示具体数量；小圆点 + 白色描边，视觉更轻。

<span class="xu_nav-icon-wrap"> <svg><use xlink:href="#icon-wode"></use></svg> <span class="xu_dot"></span> </span>
04

实现方式

SVG symbol 方案的要点：
1）引入本地 font/iconfont.js，它会把所有图标注入为隐藏的 <symbol> 精灵图；
2）HTML 中用 <svg><use xlink:href="#icon-名称"></use></svg> 引用图标；
3）导航容器 display:flex，4 项 flex:1 等分并自适应宽度；
4）position:fixed; bottom:0; left:0; right:0 固定在底部，配合 env(safe-area-inset-bottom) 适配全面屏；
5）徽章/红点用 position:absolute 挂在图标右上角；
6）本套图标中部分图标自带填充色（如“消息”为青/粉双色），SVG 的 fill 无法覆盖其内部路径，因此选中态以文字颜色与顶部指示条共同表达。 <script src="font/iconfont.js"></script> <nav class="xu_tabbar"> <a class="xu_nav-item"> <span class="xu_nav-icon-wrap"> <svg><use xlink:href="#icon-shouye1"></use></svg> </span> <span class="xu_nav-label">首页</span> </a> </nav>
