JavaScript 对象图鉴

把对象想象成一张档案卡：每格都有标签（属性名）和内容（属性值），数据按名字存放

认识对象：一张带标签的档案卡

对象（Object）用键值对存放数据：键是标签，值是内容。数组按位置找数据，对象按名字找数据。

name小明
age18
gender男
hobby篮球
let student = { name: '小明', // 属性名: 属性值 age: 18, gender: '男', hobby: '篮球' }; student.name → '小明'　　// 用"名字"取数据

创建对象的三种方式

字面量最常用；构造函数适合创建多个同类对象（像一张可复印的档案模板）。

// 方式一：对象字面量（推荐） let obj1 = { name: '小明', age: 18 }; // 方式二：new Object() let obj2 = new Object(); obj2.name = '小红'; // 方式三：构造函数（批量造对象） function Student(name, age) { this.name = name; this.age = age; } let obj3 = new Student('小刚', 19);
obj1.name小明
obj2.name小红
obj3.name小刚

访问属性：点语法 与 方括号

点语法简单直观；方括号里可以放变量，适合"名字存在变量里"或属性名带空格的情况。

> 点击按钮看取值结果

增删改游乐场：档案卡随点随变

对象非常灵活：随时可以给档案卡添一栏（新增）、改一栏（修改）、撕掉一栏（delete 删除）。

> 点击按钮，档案卡会实时变化
点语法student.age = 19：属性名写死时最方便。
方括号student['a' + 'ge']：属性名需要拼出来时用它。
delete删掉属性后，再读它就变成 undefined。

对象方法与 this：档案卡会说话

属性的值也可以是一个函数，这时它叫方法。方法里的 this 指向"当前这张档案卡"自己。

let student = { name: '小明', sayHi: function () { return '大家好，我是' + this.name; // this = student 自己 } };
> 点击"调用方法"听档案卡自我介绍

遍历对象：把档案卡读一遍

for...in 逐个取出属性名；Object.keys / values / entries 分别拿到名字、内容、成对清单。
