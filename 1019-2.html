Lucide
SVG 图标

Lucide 采用 内联 SVG（Inline SVG） 方案：页面里只写 <i data-lucide="home"></i> 作为占位，脚本在加载后调用 lucide.createIcons()，把对应的矢量路径直接替换成 <svg> 元素。 图标是真实 DOM 节点，可用 CSS 改描边、颜色、尺寸，也能单独做动画。本页脚本已下载到本地 cdn/lucide/lucide.min.js，无需联网即可使用。

05

实现方式

SVG 图标的三个要素：
1）引入本地脚本 cdn/lucide/lucide.min.js；
2）HTML 中用 <i data-lucide="名称"> 作为占位；
3）脚本加载后调用 lucide.createIcons()，把占位元素替换为内联 <svg>，再用 CSS 控制样式。 <script src="cdn/lucide/lucide.min.js"></script> <i data-lucide="rocket"></i> <script>lucide.createIcons();</script> /* CSS 直接控制生成的 svg */ .xu_tile svg { width: 30px; height: 30px; stroke: #118ab2; }
