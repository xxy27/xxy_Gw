JavaScript 数组图鉴

把数组想象成一排彩色小盒子：每个盒子都有编号（下标），数据就住在里面

认识数组：一排带编号的盒子

数组（Array）按顺序存放一组数据，每个位置都有下标，从 0 开始数。用 arr[下标] 就能取出对应盒子里的东西。

苹果arr[0]
香蕉arr[1]
橙子arr[2]
葡萄arr[3]
空位arr[4]
let fruits = ['苹果', '香蕉', '橙子', '葡萄'];
fruits[0] → '苹果'　　　fruits.length → 4

创建数组的两种方式

日常推荐字面量写法（更简洁直观）；构造函数写法在预分配长度时才用得上。

// 方式一：字面量（推荐）
let arr1 = [10, 20, 30];

// 方式二：构造函数
let arr2 = new Array(10, 20, 30); // [10, 20, 30]
let arr3 = new Array(3); // 3 个空位的空数组
10[0]
20[1]
30[2]
=
10[0]
20[1]
30[2]

增删游乐场：亲手动一动

push / pop 从队尾进出，unshift / shift 从队头进出，splice 可以在任意位置增删。点击按钮看盒子的进出！

> 点击上方按钮，这里会显示执行过的代码和返回值
栈（stack）push + pop：像叠盘子，后放的先拿，"后进先出"。
队列（queue）push + shift：像排队买票，先来的先走，"先进先出"。
返回值pop / shift 返回被删除的元素；push / unshift 返回新长度。

查找定位：在盒子里找东西

indexOf 返回元素的下标（找不到返回 -1）；includes 只回答"有没有"（true / false）。

> 点击按钮，找到的盒子会被高亮闪烁

截取 · 合并 · 拼接

slice 剪出一段副本（不动原数组）；concat 把两串盒子接起来；join 把盒子串成一根字符串糖葫芦。

let arr = [1, 2, 3, 4, 5];
