研究方向简介：本系统采用"检索增强生成（RAG）"路线。用户问题先经意图识别，再从向量知识库中召回相关知识片段， 与问题一起交给大模型生成答案，最后经敏感词过滤与置信度评估后回复用户。相比纯大模型直接回答，该架构能显著降低"幻觉"、答案可溯源、知识可实时更新， 是当前智能客服与领域问答的主流科研方向。

核心模块说明

向量检索模块把用户问题与知识库文档都映射为高维向量，用近似最近邻（ANN）算法召回语义最相关的 Top-K 片段，是 RAG 的"查资料"环节。
重排序模块召回结果用 Cross-Encoder 精排，过滤弱相关内容，直接决定送入大模型的上下文质量，是提升答案准确率的关键。
大模型生成模块将问题与知识片段拼接成 Prompt，要求模型只依据给定资料回答并标注引用，从机制上抑制幻觉。
置信度评估与转人工对答案打分，低置信度自动转人工客服，保证服务质量下限，同时把疑难问题沉淀为新的知识。
知识库构建流水线文档解析 → 语义切分 → Embedding → 入库，支持增量更新；知识运营后台保证知识时效性。
评估与数据闭环用准确率、召回率、答案忠实度（Faithfulness）等指标做自动 + 人工评估，实验数据反哺模型微调与知识治理。

可用技术与指标

Embedding 模型：BGE / text-embedding-3　·　向量库：Milvus / FAISS / Elasticsearch　·　大模型：ChatGLM / Qwen / GPT 系列
评价指标：回答准确率、知识召回率 Recall@K、忠实度 Faithfulness、用户满意度 CSAT、转人工率
