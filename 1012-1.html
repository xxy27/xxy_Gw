CSS 长度单位

绝对单位 · 相对单位 · 视口单位 — 全面解析

绝对单位

px

像素单位，1px 对应屏幕上一个物理像素点，是最常用的绝对单位。

200px 宽度
pt

磅单位，1pt = 1/72 英寸，常用于打印样式。

cm / mm / in

厘米、毫米、英寸，物理尺寸单位，主要用于打印。

pc

派卡，1pc = 12pt，印刷行业单位。

相对单位

em

相对于当前元素 font-size 的倍数。2em = 当前字体大小的 2 倍。

2em 文字
rem

相对于根元素(html) font-size 的倍数，避免嵌套叠加问题。

1.5rem 文字
%

相对于父元素的百分比，常用于宽度、高度、内边距等。

父容器的 50%
ch

相对于 "0" 字符宽度的倍数，常用于限制文本行宽。

ex

相对于当前字体 x 高度（小写字母 x 的高度）的倍数。

lh

相对于当前元素 line-height 的倍数（CSS3 新增）。

视口单位（Viewport Units）

vw

视口宽度的 1%。100vw = 整个视口宽度。

30vw 宽度
vh

视口高度的 1%。100vh = 整个视口高度。

vmin

取 vw 和 vmin 中较小值的 1%。

40vmin 宽度
vmax

取 vw 和 vmax 中较大值的 1%。

svw / svh

小视口单位，不考虑移动浏览器动态工具栏（CSS3 新增）。

lvw / lvh

大视口单位，包含动态工具栏展开时的尺寸。

dvw / dvh

动态视口单位，实时响应工具栏收缩/展开。

容器查询单位

cqw / cqh

容器宽/高度的 1%，需配合 container-type 使用。

cqi / cqb

容器内联/块轴尺寸的 1%（CSS3 新增）。

cqmin / cqmax

取容器尺寸中较小/较大值的 1%。

使用建议：布局推荐用 %、vw/vh 做响应式；字号推荐用 rem 避免嵌套问题；内边距推荐用 em 跟随字号缩放；打印样式用 pt/cm。
